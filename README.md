# スカイライン・テクノロジーズ 企業サイト

架空のソフトウェア開発会社「スカイライン・テクノロジーズ」の1ページ企業サイトです。

## 概要

Webシステム開発・モバイルアプリ開発・クラウド構築・AI活用支援などを手がける
ソフトウェア開発会社という設定で、以下のセクションを1ページにまとめています。

- ヒーロー（キャッチコピー・実績数値）
- 提供サービス
- 選ばれる理由
- 開発実績（カテゴリ別フィルター付き）
- 開発の流れ
- よくあるご質問（アコーディオン）
- 経営メンバー
- お知らせ
- お問い合わせフォーム（バリデーション付きデモフォーム）

外部ライブラリに依存せず、HTML / CSS / JavaScript を1ファイル（`index.html`）に
まとめたシンプルな構成です。

## 動作環境

- モダンブラウザ（Google Chrome、Microsoft Edge、Safari、Firefox など）
- ビルドツールやサーバーは不要です。

## 使い方（ブラウザでの開き方）

1. このリポジトリをクローン、またはダウンロードします。
   ```
   git clone <このリポジトリのURL>
   ```
2. `index.html` をブラウザで開きます。
   - エクスプローラー（Windows）や Finder（Mac）から `index.html` を
     ダブルクリックする
   - もしくはブラウザのウィンドウ・タブに `index.html` をドラッグ＆ドロップする
   - コマンドラインから開く場合は、リポジトリのディレクトリで以下を実行します。
     ```
     # Windows
     start index.html

     # macOS
     open index.html
     ```

ローカルサーバーを起動する必要はなく、ファイルを直接開くだけで閲覧できます。

## 注意事項

- 本サイトに登場する会社名・人物名・実績・お知らせなどはすべて架空のものです。
- お問い合わせフォームはデモ用であり、送信しても実際にメールは送信されません。

# スカイライン・テクノロジーズ 企業サイト

架空のソフトウェア開発会社「スカイライン・テクノロジーズ」の1ページ企業サイトです。

## 概要

Webシステム開発・モバイルアプリ開発・クラウド構築・AI活用支援などを手がける
ソフトウェア開発会社という設定で、以下のセクションを1ページにまとめています。

- ヒーロー（キャッチコピー・実績数値）
- 提供サービス
- 選ばれる理由
- 開発実績（カテゴリ別フィルター付き）
- 開発の流れ
- よくあるご質問（アコーディオン）
- 経営メンバー
- お知らせ
- お問い合わせフォーム（バリデーション付きデモフォーム）

外部ライブラリに依存せず、HTML / CSS / JavaScript を1ファイル（`index.html`）に
まとめたシンプルな構成です。

## ミニゲーム「バグ退治チャレンジ」

`game.html` に、ブラウザで遊べるミニゲームを収録しています。
トップページのナビゲーションとフッターの「🐛 ミニゲーム」からも開けます。
こちらも外部ライブラリなしの1ファイル構成です。

- 画面に出てくるバグをクリック（タップ）して退治し、60秒間システムを守り抜きます。
- 難易度を選べます（かんたん / ふつう / むずかしい）。ハイスコアは難易度ごとにブラウザへ保存されます。
- システムHP制です。バグを逃したり、「仕様です」（✅）を誤って退治したりするとHPが減り、0になるとゲームオーバーです。
- 連続で退治するとコンボ倍率が上がります（10コンボごとに +1、最大 ×4）。空振りやバグを逃すとコンボは途切れます。
- 15秒ごとにウェーブが進み、敵が速く・強くなります。偶数ウェーブにはボスが出現し、倒すと +5秒です。
- 敵の種類：バグ（🐛）、ランナー（🪲）、装甲バグ（🕷️）、ゴールド（🐝）、ボス（👾）、デコイ（✅）
- パワーアップ：フリーズ（⏱️）、ボム（💣）、リペア（🔧）
- 終了時にランク（S / A / B / C）と統計（撃破数・最大コンボ・命中率など）が表示されます。効果音はミュートできます。

## 動作環境

- モダンブラウザ（Google Chrome、Microsoft Edge、Safari、Firefox など）
- ビルドツールやサーバーは不要です。

## 使い方（ブラウザでの開き方）

1. このリポジトリをクローン、またはダウンロードします。
   ```
   git clone <このリポジトリのURL>
   ```
2. `index.html` をブラウザで開きます。
   - エクスプローラー（Windows）や Finder（Mac）から `index.html` を
     ダブルクリックする
   - もしくはブラウザのウィンドウ・タブに `index.html` をドラッグ＆ドロップする
   - コマンドラインから開く場合は、リポジトリのディレクトリで以下を実行します。
     ```
     # Windows
     start index.html

     # macOS
     open index.html
     ```

ローカルサーバーを起動する必要はなく、ファイルを直接開くだけで閲覧できます。
ミニゲームで遊ぶ場合は、`game.html` を同じ方法で開いてください。
